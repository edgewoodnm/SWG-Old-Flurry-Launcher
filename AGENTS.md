This repository distributes the Old Flurry launcher and a separate sanitized base client. Keep all future custom asset updates compatible with edgewoodnm/SWG-Old-Flurry-Assets/main/manifest.json: version, packageUrl, size, sha256. Custom asset payloads must be TRE-only, with client.cfg registration allowed. Retain original installer limits: 1,000 entries, 100 MiB per extracted file, 500 MiB total. Never upload local user/login configuration, profiles, browser databases, character lists, logs, private Git repositories or credentials. Base-client login/user defaults are generated locally by the installer. Verify every uploaded release asset size and SHA256 before publishing any manifest. Test forced-update gating, corruption detection, ZIP validation, rollback and fresh base installation before release.
